# Sreekesh Photography

A premium, dark editorial photography portfolio website built around Sreekesh's uploaded photographs.

## Included
- Responsive one-page portfolio
- Signature-style Sreekesh wordmark
- Full-screen hero
- Filterable portfolio
- Click-to-expand lightbox
- About/profile section using the uploaded photographer portrait
- Services
- WhatsApp enquiry form
- Mobile navigation

## Before publishing
Open `script.js` and replace:
`919999999999`
with your real WhatsApp number in international format, without `+` or spaces.

The Instagram footer link can also be changed to your real photography profile.

## Hosting
This is a static website. It can be uploaded directly to Cloudflare Pages, GitHub Pages, Netlify, Vercel, or most normal web hosting.
